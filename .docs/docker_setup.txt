# Docker Infrastructure Strategy

## 1. Internal Services Stack
- **postgres**: Standard PostgreSQL for the Device Registry.
- **timescaledb**: Specialized TimescaleDB image (Postgres + TimescaleDB extension) for telemetry.
- **redis**: Used for deduplication (Telemetry) and alert state (Silence logic).
- **mosquitto**: The internal broker. 
  - **Port 8883**: mTLS enabled.
  - **Config**: Mounts `mosquitto.conf` and `certs/` directory.
  - **Auth**: `require_certificate true`, `use_identity_as_username true`.

## 2. Remote Simulation Stack
- **mosquitto-remote**: A second Mosquitto instance.
  - **Port 1883**: Plain MQTT (no TLS) to simulate client-managed brokers.

## 3. Observability
- **uptrace**: Or a collector agent that forwards to Uptrace. We'll use the OpenTelemetry Collector to handle high-volume trace ingestion first.

## Docker Compose Structure (Conceptual)
```yaml
services:
  postgres:
    image: postgres:15-alpine
    environment:
      POSTGRES_DB: device_registry
  
  timescaledb:
    image: timescale/timescaledb:latest-pg15
    environment:
      POSTGRES_DB: telemetry_db

  redis:
    image: redis:7-alpine

  mosquitto:
    image: eclipse-mosquitto:2.0
    ports:
      - "8883:8883"
    volumes:
      - ./configs/mosquitto.conf:/mosquitto/config/mosquitto.conf
      - ./certs:/mosquitto/config/certs

  mosquitto-remote:
    image: eclipse-mosquitto:2.0
    ports:
      - "1883:1883"

  # App Services will be added here
  device-service:
    build: ./device-service
    depends_on: [postgres, mosquitto]
    environment:
      ROOT_CA_KEY: ${ROOT_CA_KEY}

  telemetry-service:
    build: ./telemetry-service
    depends_on: [timescaledb, redis, mosquitto]

  alert-service:
    build: ./alert-service
    depends_on: [postgres, redis, mosquitto]

  api-gateway:
    build: ./api-gateway
    ports: ["8080:8080"]
    depends_on: [device-service, telemetry-service]
```

## Volume Strategy
- `./migrations`: Shared volume for SQL scripts.
- `./certs`: Shared volume for certificates generated by `bootstrap-ca.sh`.
- `./data`: Persistent storage for DBs (not committed to git).
